# Publication and reproduction scope

Published: original project prose, original editable diagrams, original aggregate plotting/validation code and a minimal extract of frozen numerical summaries. Figure rendering uses Matplotlib and standard fonts; it does not reuse external illustrations.

Excluded: raw episodes, prompts/replies, per-episode seeds or identifiers, fitted coefficients, complete evidence snapshots, private source archives, full logs, machine paths, internal hostnames, weights/checkpoints, upstream SPA code, third-party papers and datasets, caches and build files. Their redistribution rights have not been established where applicable.

The private evidence record remains preserved. Public aggregates reproduce figure/table values but cannot reproduce the original model execution, feature extraction, fit or bootstrap. No such rerun is claimed.

No repository-wide license has been selected. Public access alone does not grant an unrestricted reuse license, and nothing in this repository relicenses third-party assets. Cite upstream work and consult its own terms.
